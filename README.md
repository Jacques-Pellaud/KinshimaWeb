# Kinshima Web

Export autonome du site Kinshima basé sur Next.js.

## Prérequis

Node.js 24 (version indiquée dans `.nvmrc`) et npm.

## Lancer en développement

```powershell
npm ci
npm run dev
```

Ouvrir ensuite http://localhost:3000.

## Build de production

```powershell
npm run build
npm start
```
